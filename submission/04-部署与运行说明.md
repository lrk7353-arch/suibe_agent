部署与运行说明
版本与目录
阶段提交 v0.1；app 为校园 API 候选版，trade-demo 为可独立启动的经贸演示，acceptance 为历史验收基线。完整本地模型版单独保留。
快速演示
安装 Node.js 24，在仓库根目录执行：node trade-demo/src/server.cjs --port 18870。浏览器访问 http://127.0.0.1:18870 。默认规则解析模式，不调用模型、不需要密钥。Ctrl+C 停止。
校园 API 环境
准备 Python 3.14 与 Node.js 24。在 app 内将 TEMP、TMP、HF_HOME、PIP_CACHE_DIR 指向项目 tmp 目录，创建 .venv 后安装 requirements.txt。首次将 BAAI/bge-small-zh-v1.5 下载到 app/models/bge-small-zh-v1.5。所有新增环境和缓存放在非 C 盘项目目录。
校园 API 启动
设置服务端 DEEPSEEK_API_KEY。分别运行 python -B rag-service.py 和 node assistant.cjs。访问 http://127.0.0.1:18866/ 。检索端口为 18867。不要把密钥写入前端或提交到仓库；.env.example 不会自动加载，须显式设置环境变量。
真实模型经贸模式
设置 TRADE_DEMO_MODEL_URL=https://api.deepseek.com，TRADE_DEMO_MODEL=deepseek-flash，TRADE_DEMO_MODEL_KEY 为本地密钥，再启动演示。模型只提出参数，金额由工具计算。此配置尚需真实 API 验证。
成功标志与排障
规则演示页面应显示模拟模式和可填写案例。校园 /health 检查检索版本与密钥配置，不等于远程 API 已验证。端口占用时更换端口，不结束其他任务。网络或密钥错误时保留输入并检查日志。
版本边界
公开校园样例仅含借阅服务与独立网络工具，不能用于证明完整 v1.3 覆盖率。完整模型包已做过独立目录测试；本 API 候选版尚无真实密钥端到端验收。
