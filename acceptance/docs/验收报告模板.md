## 11. 复现步骤

```bash
# 1. 静态校验
python -I scripts/validate_cases.py --cases cases/cases.jsonl --out reports/static-validation/validation.json

# 2. 检索层
python -I scripts/retrieve_eval.py --kb v12 --cases cases/cases.jsonl --run-dir runs/<run-id> --k 8
python -I scripts/retrieve_eval.py --kb v13 --cases cases/cases.jsonl --run-dir runs/<run-id> --k 8

# 3. 工具层
python -I scripts/tool_eval.py --cases cases/cases.jsonl --run-dir runs/<run-id>

# 4. 生成/端到端（交付模型启动后）
python -I scripts/generation_eval.py --cases cases/cases.jsonl --endpoint http://127.0.0.1:18768 --run-dir runs/<run-id>
python -I scripts/e2e_eval.py --cases cases/cases.jsonl --base-url http://127.0.0.1:18766 --run-dir runs/<run-id>
```
