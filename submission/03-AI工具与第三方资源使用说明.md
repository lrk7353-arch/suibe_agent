AI 工具与第三方资源使用说明
大模型
API 主版本配置 DeepSeek Flash（deepseek-flash），用于自然语言解释与参数提案；密钥仅在服务端环境变量中读取。真实 API 联调尚未验收。离线补充版本使用 Gemma 4 E2B IT Q4_K_M，经 llama.cpp 运行。历史研发比较过 Qwen 小模型，当前公开包不含其权重。
开发辅助
Codex、ZCode 用于代码实现、测试、资料整理、交付打包及文档草拟。AI 辅助复核不是团队成员人工签字。成员应对最终材料和代码承担复核责任。
开源与运行组件
Node.js、Python、NumPy、PyTorch、Transformers、Sentence Transformers、BAAI/bge-small-zh-v1.5、llama.cpp，以及文档生成工具 ReportLab。遵守各原项目许可证；本仓库未重新授权第三方权重或学校材料。
知识来源
上海对外经贸大学官网、图书馆、信息化办公室等官方服务资料。公开包限量收录服务页样例，并保留 URL；全量抓取原件和历史资料未全部公开。引用不表示学校对本项目背书。
数据与调用
API 版会向 DeepSeek 发送用户问题与选定证据片段。不得提交密钥、个人敏感信息或未获授权资料。运行日志不进入 GitHub。
模型获取
本地模型使用原 Hugging Face 仓库固定版本及 SHA256 下载；不将 GB 级权重放入邮件或 Git 仓库。离线模型不是 API 版运行前提。
