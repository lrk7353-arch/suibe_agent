# 架构

## 校园

HTTP 输入 → 会话归一化 → 固定工具或 RAG → Python 检索 → 证据选择 → DeepSeek → 引用检查 → 网页。

检索结合 BGE 向量相似度和词法匹配，按集合、主题与适用条件筛选，限制同文档片段数量。文档、分块与向量形成一个数据版本。

## 经贸

输入 → 规则或模型提案 → 参数校验 → 方案状态更新 → 确定性计算 → 对比与解释 → 导出。

金额使用十进制工具计算。缺参进入澄清流程；敏感性试算与已保存方案的修改分开处理，导出时重新核对结果。

## 服务

两个应用独立启动。校园默认端口 18866/18867，经贸根启动命令指定 18870。密钥只在服务端读取，运行记录写入各应用内的忽略目录。
