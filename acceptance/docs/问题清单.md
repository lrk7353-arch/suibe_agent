## 修复优先级建议

1. **P0-1 知识接入**：先让 2026-2027 高频事实有可核验来源。
2. **P0-2/P0-3 检索召回与证据完整性**：先修召回，再调生成。
3. **P1-1/P1-2/P1-3/P1-4/P1-5 元数据与附件**：这些会持续制造“看起来命中、其实答错”。
4. **P1-6/P1-7/P1-8 资料污染与时效**：目录页、活动页、无日期页。
5. **P2 生成/端到端/稳定性**：交付模型启动后一次性补齐。
