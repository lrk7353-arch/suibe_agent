小贸：上经贸大校园与经贸智能体
团队：let me go；孔令睿（队长）、陈相彤。方向：经贸与校园赋能智能体。阶段版本 v0.1。
问题背景
校园办事资料分散在官网、服务指南和通知中；同学需要核对身份、年份与办理条件。经贸课程案例则常涉及币种、报价口径和多轮参数修改，直接让模型心算容易出现口径混淆。
目标用户
上海对外经贸大学学生，以及需要演示进口成本教学案例的参赛团队。作品为学生项目，不代表学校官方办事平台。
技术方案
校园模块：检索知识片段，筛选适用范围，再通过 DeepSeek Flash 组织回答并附来源。经贸模块：模型或规则提出参数，程序校验，确定性工具计算，状态机管理方案与导出。网页提供桌面与移动布局。
项目摘要
小贸将校园资料检索与经贸案例决策结合。校园问答强调来源、适用范围和缺失信息提示；经贸案例支持从缺参追问到 FOB/CIF 方案比较、汇率敏感性分析和摘要导出。主要交付为 API 源码版，另具备 Gemma 本地离线版本，权重不随 GitHub 提交。当前经贸规则与工具层 41 条用例通过，校园验收建立 115 条用例；真实 API 和生成正确率仍待验证。
创新与应用价值
重点是可追溯的证据回答、可复算的经贸计算、可恢复的多轮状态，以及分层验收。并非宣称原创基础模型。离线版本可作为网络受限场景的补充。
阶段成果与限制
公开仓库提供官方服务页样例，完整 v1.3 数据为 650 文档、3879 分块，留存于本地交付包。公开样例不等于完整校园覆盖。当前没有正式人工签字或真实模型端到端正确率结论。
