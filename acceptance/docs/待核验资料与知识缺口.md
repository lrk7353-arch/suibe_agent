## 5. 需要人工复核的重点

以下条目在本轮只做了“来源定位 + 引文逐字命中”，尚未逐条人工签字：

1. 所有 `critical` 用例（金额、资格、外校归属、工具计算）；
2. 收费表的列对应关系（专业类别 → 金额 → 合计）；
3. 2024/2025/2026 三个年度表格的差异（专升本 5000→6500、合计 6200→7700）；
4. 食堂人工识读表（`doc_94321d5ec40f` 的 `manual-canteen-2026`）与原图是否一致；
5. 报修电话表（含长宁 `09:01-06:59（原文如此）` 的异常写法）；
6. 辅修 125 元/学分、论文 200 元/学分的适用学年；
7. 外校通知的“本校/我校”指代；
8. 2027 级/留学生/研究生住宿费等“无资料”结论是否确实无资料，而不是未检索到。

复核人签字后，把 `review_status` 从“自动初评”改为“已人工复核”，并记录复核日期与依据。

1. 先跑 `validate_cases.py`，确认新增文档的引文逐字命中；

5. 重新冻结版本号、更新 `VERSION.json`/`app.config.json`/`kb-active.json` 和 SHA-256；
